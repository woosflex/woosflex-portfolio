# Contributing to woosflex-portfolio

Thanks for considering a contribution. This is a personal portfolio site, so the
scope of community contributions is intentionally small, but issues and PRs are
welcome.

## Code of Conduct

Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Developer Certificate of Origin (DCO)

By contributing you agree to the [Developer Certificate of Origin](https://developercertificate.org/)
(v1.1). Sign off commits with `git commit -s`.

## How to Contribute

1. Fork and clone.
2. Create a topic branch (`fix/...`, `feat/...`, `docs/...`).
3. Make a small, focused change.
4. Run `npm run check` (typecheck) and `npm run build` to ensure it compiles.
5. Open a PR, referencing any related issue.

## Reporting Issues

Include the browser/environment, a clear description, and expected vs actual
behavior. Security issues: use the private channel in [SECURITY.md](SECURITY.md).
