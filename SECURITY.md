# Security Policy

## Reporting a Vulnerability

Do **not** open a public issue for security vulnerabilities. Report privately:

**Email:** adnanraza3435@gmail.com

Include: environment, a description and impact, a minimal reproduction, and a
suggested fix if known. The maintainer will acknowledge and coordinate
disclosure; do not disclose publicly until a fix is available.

## Scope

The Express API server and any endpoints that accept user input are the primary
security surface. Report data-exposure, injection, or auth issues here.
